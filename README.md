# Contador de Tempo de Jogo em C++

Primeiro projeto desenvolvido durante meus estudos de Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

Programa desenvolvido em C++ para calcular a duração de uma partida de jogo a partir da hora de início e da hora de término.

O programa também considera partidas que ultrapassam a meia-noite.

## Conceitos utilizados

* Variáveis inteiras
* Entrada e saída de dados
* Estrutura condicional `if/else`
* Operações matemáticas
* Lógica de programação
* C/C++

## Tecnologias

* C++
* Biblioteca `iostream`
* Biblioteca `cstdio`
* Biblioteca `locale.h`

## Objetivo

Praticar conceitos básicos de programação e desenvolver o raciocínio lógico por meio de um problema prático.
